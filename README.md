installation
-------------------------------
to install, clone the repository, or pick up the source code from the releases.
that's all. (for linux)

---------------------------------------------------------------------------------------------------

windows installation
--------------------
to run beetles on windows, you will need to first install wsl.
to do so, open command prompt and run the commands
wsl --install   
wsl --install -d Ubuntu

to open wsl, you can easily search for "Ubuntu" in your search menu and run it. this will open a cmd window.
once wsl has started, it should look something like this

username@computer-name:~$

once you do, please run the following command in the shell;

sudo apt update && sudo apt install mpv git

it will ask you for your password to install the packages. once finished, you will need to cone this repository.

git clone https://github.com/bludfud/beetles

and then go to the repo directory

cd beetles

before running, please run the command 

cat README

to see the instructions you will now have to follow.
